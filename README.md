# 🏎️ Car Racing Game App

> A Windows desktop car-racing game built with C# and Windows Forms.

## Overview

This project is a desktop racing-game application focused on an interactive driving experience, keyboard input, game-state updates, and a graphical Windows Forms interface.

## Technology

- C#
- .NET 6 for Windows
- Windows Forms
- Visual Studio solution and project files

## Run Locally

Prerequisites:

- Windows
- .NET 6 SDK
- Visual Studio with the Desktop development with .NET workload

Open [`Car Racing Game App.sln`](./Car%20Racing%20Game%20App.sln) in Visual Studio and press **F5** to build and run the game.
